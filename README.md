# plat5dev/homebrew-tap

Homebrew formulae for Plat5.

```bash
brew install plat5dev/tap/plat5
plat5 version
```

`Formula/plat5.rb` is written by the [cli](https://github.com/plat5dev/cli) release workflow (goreleaser) on every tag. Don't edit it by hand.

Without Homebrew:

```bash
curl -fsSL https://plat5.com/install.sh | sh
```
